# German Cultural Reward-Model Evaluation

This repository contains the reproducible code and canonical data for a Germany-first cultural red-team benchmark. The primary experiment measures whether a general reward model selects the same response as independent human annotators in a Best-of-4 setting. An evidence-based verifier and a hybrid selector are secondary experiments.

## Current scientific status

- The canonical benchmark contains 300 prompts (`RT001`–`RT300`), 10 domains, 30 subdimensions, and 10 attack types.
- Development, verifier-validation, and held-out test splits are frozen in `data/benchmark/splits.csv`.
- A legacy 30-prompt × 4-candidate pilot is retained for diagnostics only.
- Its labels are explicitly marked as **synthetic provisional annotations** and must not be reported as human labels.
- Final `RT` candidates and independent human labels have not yet been collected.
- The evidence-bank plan is complete for all 300 prompts. Retrieved evidence is generated by agentic web search at run time and is not restricted to a website allowlist.

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[dev]'
python scripts/validate_data.py
python -m unittest discover -s tests -v
```

Install reward-model dependencies only on a machine that will run Skywork:

```bash
python -m pip install -e '.[reward]'
```

## Evidence retrieval

Set `OPENAI_API_KEY`, then run:

```bash
python scripts/build_evidence_bank.py \
  --claims data/evidence/reference_claims.csv \
  --output-dir artifacts/evidence/reference-bank
```

Retrieval uses the Responses API `web_search` tool with a reasoning model. No domain allowlist or `site:` filter is applied. The search agent records its queries, consulted sources, citations, and response metadata. A separate judge call receives only the retrieved evidence and has no web-search tool.

## Evaluation order

1. Generate four responses for each final `RT` prompt.
2. Remove unusable sets and regenerate any set with no acceptable answer.
3. Randomize candidate order.
4. Collect two independent blind human annotations and adjudicate disagreements.
5. Calibrate verifier parameters on `development` only with `scripts/calibrate_scoring.py`.
6. Freeze configuration and evaluate once on `test`.
7. Report Skywork Best-of-4 accuracy as the primary result; verifier and hybrid results are secondary.

See `docs/methodology.md` and `docs/research_integrity.md` before reporting results.
