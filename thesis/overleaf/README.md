# Overleaf project

This folder is directly importable into Overleaf.

## Import
1. Download the thesis/overleaf folder as a ZIP.
2. In Overleaf choose New Project -> Upload Project.
3. Upload the ZIP.
4. Set main.tex as the main document if Overleaf does not detect it.

Compiler: pdfLaTeX with Biber.

## Status
The project contains the rewritten abstract, Chapters 1-10, appendices, a bibliography file, tables, code listings, and explicit result placeholders.

It is not submission-ready yet. The final experiment results, baseline results, exact code excerpts, source-level literature verification, title-page information, figures, and the 60+ page expansion still have to be completed.

Do not replace result placeholders with guessed numbers.
