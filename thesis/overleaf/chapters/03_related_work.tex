\chapter{Related Work and Research Gap}
\label{chap:related}

\section{How Culture Is Evaluated in LLM Research}

There is no single standard test for cultural capability. Some papers ask factual questions about everyday life. Others study social norms, values, safety, or model preferences. This matters because good performance on one task does not automatically transfer to another.

Two surveys help to organise the field. Adilazuarda et al. review how culture is represented and measured in LLM research \parencite{adilazuarda2024culture}. Liu et al. provide a broader taxonomy of culturally aware and culturally adapted NLP systems \parencite{liu2025culturally}. Both make clear that culture is represented through several signals, such as language, region, values, social groups, and local practices.

For this thesis, the useful lesson is simple: cultural evaluation needs more than a country label. This is one reason why Vericult first extracts the context that is actually present in the prompt.

\section{Cultural Knowledge Benchmarks}

BLEND tests everyday cultural knowledge across languages and regions \parencite{myung2024blend}. Its questions cover ordinary topics that local users may know even when such information is not strongly represented online. This is close to D01 in Vericult, which covers food, clothing, celebrations, and other everyday practices.

CulturalBench takes a different approach. It contains difficult, human-written cultural questions from many regions and topics \parencite{chiu2025culturalbench}. The paper also discusses cases where more than one answer can be reasonable. That point is especially useful for this thesis. If a custom varies by region or situation, a verifier should not reject a response only because it differs from the first description found online.

Both benchmarks mainly test whether a model knows the answer to a fixed question. Vericult instead receives an open-ended response and has to decide which parts of that response are worth checking.

\section{Norms and Context: NormAd}

NormAd studies whether models can recognise and apply social norms in different cultural settings \parencite{rao2025normad}. The work is relevant because it separates general values from more specific norms and situations.

This supports two choices in Vericult. First, the prompt context should be read before the response is scored. Second, the system should be allowed to remain uncertain when the prompt or evidence is too weak for a confident cultural judgment.

NormAd still uses its own benchmark task, so its accuracy numbers are not directly comparable with the final Vericult experiment.

\section{Changing the Generator: CultureLLM}

CultureLLM aims to improve the generator itself by adapting models to cultural differences \parencite{li2024culturellm}. It uses culturally related data and fine-tuning so that the model gives answers that better match the target culture.

Vericult works at another stage. It does not change the generator. The response is already fixed when verification starts. CultureLLM is therefore useful as background on cultural adaptation, but it is not a direct baseline for this thesis.

\section{Reward Models and Cultural Preferences}

Reward models learn a score over responses. RewardBench evaluates how well such models handle different types of preference comparisons \parencite{lambert2025rewardbench}. M-RewardBench extends this question to multilingual settings and reports clear differences between English and non-English evaluation \parencite{gureja2025mrewardbench}.

These studies matter because a high reward score is not the same as a verified cultural claim. A reward model can prefer a response without showing which cultural statement it accepted or rejected.

CARB is especially close to the topic of this thesis. Zhang et al. study whether reward models are culturally aware and propose CARB as a culture-focused reward-model benchmark \parencite{zhang2025carb}. Their work shows that reward models can react to cultural signals in ways that do not always reflect the deeper meaning of the situation.

Vericult addresses a related problem, but with another method. It does not learn a reward function and it does not use CARB scores inside the verifier. Skywork is only an external baseline in the final experiment.

\section{Direct LLM Judges}

Another common approach is to ask an LLM to judge the answer directly. Zheng et al. study this setup in MT-Bench and Chatbot Arena \parencite{zheng2023judging}. Wang et al. show that the order of responses can influence comparative judgments \parencite{wang2024fair}.

The final Vericult task uses one response at a time, so pairwise position bias is less relevant. Other problems remain. A judge can still rely on incomplete knowledge or give a confident explanation that is hard to verify. This is why the direct judge is kept as a simple comparison system rather than used inside Vericult.

\section{Pluralism, Values, and Disagreement}

Not every cultural question has one correct answer. Sorensen et al. argue that alignment systems should make room for reasonable disagreement instead of forcing one global preference \parencite{sorensen2024pluralistic}. This is relevant when the issue is a value conflict rather than a factual claim.

Human annotation has the same problem. Plank argues that label variation is often meaningful rather than pure noise \parencite{plank2022labelvariation}. Artstein and Poesio review agreement measures for annotation studies \parencite{artstein2008agreement}, while Krippendorff provides a broader framework for reliability in content analysis \parencite{krippendorff2018content}.

This literature is useful for interpreting the old five-person pilot in this project. Low agreement does not mean that every annotation is useless. It means that cultural appropriateness can be genuinely ambiguous and that a single majority label should be treated carefully.

\section{Intercultural Pragmatics}

Culture also affects how language is used between people. Kecskes studies this under intercultural pragmatics \parencite{kecskes2014intercultural}. Register, directness, forms of address, humour, and regional expressions can all change with the speakers and the situation.

This supports D02 in the Vericult rubric. A sentence can be grammatically correct and factually harmless while still being a poor choice for a specific professional or regional setting.

\section{Abstention}

A system does not always need to produce a label. Selective-classification research studies models that can reject uncertain cases instead of predicting on every input \parencite{geifman2017selective}. Vericult does not implement that method directly, but it follows the same basic idea.

If a dimension depends on external evidence and that evidence remains too weak, the dimension can abstain. This is preferable to presenting a precise score that hides uncertainty.

\section{Research Gap}

The literature already covers cultural knowledge, social norms, culturally adapted generators, reward models, and direct judges. I therefore do not claim that Vericult introduces each of these ideas separately.

The gap I focus on is narrower. I want an evaluator that can take one already generated response, select the culturally important claims, check the externally verifiable ones with a separate evidence stage, keep uncertainty visible, and preserve enough trace information to explain how the final judgment was reached.

That combination is what the next chapters define and test.
