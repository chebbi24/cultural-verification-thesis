\section*{Required execution order}
The final run follows the pre-declared sequence from \cref{sec:experiment-freeze}: finalize and hash human annotations; freeze the evaluation sample; freeze model configurations and analysis seeds; acquire and archive LIVE evidence; evaluate the verifier in REPLAY; run the independent Skywork baseline; run the direct judge; compute the pre-declared metrics and paired statistics; and only then select trace-backed cases for qualitative analysis. Deviations must be recorded explicitly.

\section*{Artifact inventory}
The final submission archive should contain, or provide stable repository references to, the evaluation-set file, annotation export, experiment manifest, verifier traces, evidence schedules/snapshots, Skywork outputs, direct-judge outputs, statistical-analysis outputs, figure-generation scripts, and the exact thesis source used for submission.
